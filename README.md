# Business Performance Analytics Dashboard

Power BI dashboard developed to analyze sales performance, profitability, customer behavior, and regional trends using the Superstore dataset.

## Project Overview

This dashboard provides an executive view of business performance through key metrics and interactive visualizations.

The objective is to support data-driven decision-making by identifying revenue drivers, profitable product categories, customer segments, and geographic opportunities.

## Tools & Technologies

- Power BI
- DAX
- Power Query
- Data Modeling
- Data Visualization

## Key Metrics

- Total Revenue
- Total Profit
- Total Customers
- Units Sold
- Profit Margin %

## Dashboard Features

### Executive KPIs
- Revenue
- Profit
- Customers
- Units Sold

### Sales Analysis
- Revenue trends over time
- Performance by category
- Performance by sub-category

### Customer Analysis
- Top 10 customers by revenue
- Customer profitability

### Geographic Analysis
- Revenue and profit by state
- Regional performance comparison

## Key Insights

- Technology products generated the highest profitability.
- Revenue concentration was identified among top customers.
- Significant differences were observed between product categories.
- Regional analysis highlighted areas with stronger business performance.

## Business Value

This dashboard demonstrates how business intelligence tools can be used to transform raw sales data into actionable insights for management and strategic planning.
